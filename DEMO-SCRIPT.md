## Error Handling During Recording

| Problem | Solution |
|---------|----------|
| API timeout | Wait 20 seconds. If still loading, click "Try Demo" button instead |
| Photo upload fails | Try a different photo format (.jpg works best) |
| Voice doesn't play | Click play again. Check browser audio permissions |
| Results look wrong | Re-record just that scene. Edit later |
| .avif not accepted | Skip photo for emergency, use text-only input |
